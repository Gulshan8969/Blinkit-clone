Blinkit Clone

A front-end clone of the Blinkit (quick-commerce grocery delivery) website, built with HTML and CSS.

Live Demo

https://gulshan8969.github.io/Blinkit-clone/

(Available once GitHub Pages is enabled in the repository settings.)

Tech Stack
HTML5
CSS3
Project Structure
Blinkit-clone/
├── index.html    # Page structure and content
├── style.css     # Styling and layout
└── README.md     # Project documentation
Getting Started
Clone the repository:
bash
   git clone https://github.com/Gulshan8969/Blinkit-clone.git
Go into the project folder:
bash
   cd Blinkit-clone
Open index.html in your browser (or use the Live Server extension in VS Code).
